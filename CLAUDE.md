# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Insurance REST API, Spring Boot 4.1.2 on Java 17, built with Maven via the Maven Wrapper. Base package `com.rthiam.insurance`. The project is at its skeleton stage: only a health endpoint exists (`GET /api/health` returns `{"status":"UP"}`), no business entities yet.

## Mandatory rules

- Always answer and explain in French.
- No emojis in code, comments, commit messages or resources.
- Target Java 17: do not use language features or APIs from later Java versions.
- Build tool is Maven (through the wrapper): do not introduce Gradle or another build tool.

## Commands

Always use the wrapper (`mvnw.cmd` on Windows, `./mvnw` in Git Bash), not a global `mvn`.

- Build and run all tests: `./mvnw clean verify`
- Run all tests: `./mvnw test`
- Run a single test class: `./mvnw test -Dtest=HealthControllerTests`
- Run a single test method: `./mvnw test -Dtest=HealthControllerTests#healthReturnsUp`
- Run the app: `./mvnw spring-boot:run` (port 8080; blocks until Ctrl+C)
- Run the packaged jar: `java -jar target/insurance-api-0.0.1-SNAPSHOT.jar`

There is no linter or formatter configured.

## Architecture notes

- Spring Boot 4 uses modular starters: web is `spring-boot-starter-webmvc` (not `spring-boot-starter-web`), and each starter has a matching `*-test` starter. Test slice annotations moved accordingly, e.g. `@WebMvcTest` is imported from `org.springframework.boot.webmvc.test.autoconfigure`. The H2 console comes from the separate `spring-boot-h2console` module.
- Persistence: in-memory H2 (`jdbc:h2:mem:insurancedb`), schema generated by Hibernate (`ddl-auto=update`), so data is lost on every restart. `open-in-view` is disabled: lazy associations must be loaded inside the service/transaction layer, not in controllers. H2 console at `/h2-console`.
- Web layer lives in the `com.rthiam.insurance.web` subpackage; new packages must stay under `com.rthiam.insurance` to be picked up by component scanning.
- Tests: `@SpringBootTest` for full context, `@WebMvcTest` + `MockMvc` for controller slices.

## Conventions

- No Lombok: write constructors, getters and setters explicitly.
- Source code, comments and resources must contain ASCII only (no emojis, no accented or special characters). The host Windows default encoding is Cp1252.
- UTF-8 is forced in `pom.xml` (source encoding, plus `-Dfile.encoding=UTF-8` for `spring-boot:run` and Surefire); keep these settings when editing the pom.
- `.gitattributes` keeps `mvnw` in LF and `*.cmd` in CRLF; do not change line endings of the wrapper scripts.
